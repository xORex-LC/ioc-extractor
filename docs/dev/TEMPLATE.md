## Обзор

- **Назначение.** Что решает, в терминах домена.
- **Граница (не делает).** Что сознательно вне этой способности.
- **Задействованные модули.** Список Maven-модулей, через которые проходит
  способность, — здесь «карта по модулям» складывается для читателя (напр.:
  `core/ioc-application` (use cases/stages) · `adapter-transport-smb` (SMB) ·
  `bootstrap/ioc-app` (wiring/lifecycle)). Реестр каждого модуля — в его
  `README.md`; здесь — только те, что участвуют.

## Как это работает

Основной поток данных/управления. Разрешена ASCII-диаграмма потока. Держим на
уровне «что за чем и почему в таком порядке», без пересказа кода построчно.

```text
[вход] ──stage/port──▶ [шаг] ──▶ [шаг] ──▶ [выход]
```
