# Russian ADR versions

Use the [ADR index](../README.md#records) to navigate all 49 English/Russian pairs.
ADR-0000–ADR-0019 here are Russian historical originals with approved relative-link
rebasing to their existing English destinations. ADR-0020–ADR-0048 here are labelled
Russian translations of unchanged English originals.

[Preservation rules](../README.md#languages-and-historical-preservation),
[provenance](../translation-provenance.tsv) and
[mechanical link changes](../translation-link-rebases.tsv) describe the migration.
Historical statuses, examples and plans are retained; this collection does not
claim that every recorded implementation detail remains current.
